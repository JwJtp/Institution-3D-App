Put recorded lesson videos (MP4) in this folder, then list them in public/campus.js under lessonVideos, for example:

  lessonVideos: {
    heart: './assets/videos/heart.mp4',
    brain: './assets/videos/brain.mp4',
  },

Topic ids are in src/data/topics.js (flower, joints, digestive, lungs, animalCell, embryo, plantCell, heart, neuron, brain, kidney, pollination, eye, mendel, fission, mitosis, chloroplast, alveoli, dnaStructure, dnaReplication, translation, repro, cycle, embryosac).
